## Contenido del Repositorio

El enfoque principal de este repositorio es el almacenamiento de cuadernos interactivos:

*   **Notebooks de Trabajo (.ipynb):** Archivos que contienen la implementación técnica, el análisis de datos, el entrenamiento de modelos y las conclusiones asociadas a cada entrega del curso de IA.

## Uso y Ejecución

Para visualizar y ejecutar los notebooks de trabajo correctamente, se recomienda seguir estos pasos:

1.  **Clonación:** Clonar este repositorio en el entorno de desarrollo local.
2.  **Entorno de Ejecución:** Asegurar la instalación de [Jupyter Notebook](https://jupyter.org/) o un entorno compatible (como VS Code con la extensión de Jupyter). Alternativamente, es posible cargar los archivos en plataformas en la nube como Google Colab.
3.  **Dependencias:** Verificar que el entorno Python cuente con las librerías necesarias (por ejemplo, numpy, pandas, scikit-learn) según lo requiera cada notebook.
4.  **Ejecución secuencial:** Ejecutar las celdas de código paso a paso para replicar los resultados de los modelos y el análisis de datos.
